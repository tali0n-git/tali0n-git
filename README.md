# Thalyann Olivo (tally-ANN) 👋

Data Science Apprentice at [718 Digital Labs](https://www.theknowledgehouse.org/), building LLM features and the plumbing underneath them. I connect API services, make messy data legible, and figure out what's actually breaking.

### What I'm building

- **[ALVI](https://alvi-ai.com)** — a RAG assistant for pet owners. Custom scraper → vector knowledge base → semantic chunking → context injection, plus a system-prompt architecture governing scope and safety. Deployed prototype.
- **AI homework generator** @ 718 Digital Labs — I own the instructor request queue and the API contract between it and our Teaching & Learning dashboard.
- **[NYC Schools × Transit](https://github.com/tali0n-git/NYC_Public_Schools_Analysis)** — multi-source Python pipeline joining NYC OpenData school metrics with MTA data, clustered to surface how transit access tracks with student outcomes.
- **Enigma emulator on an ATtiny85** — because constrained hardware is good for the soul.

### How I work

I use AI coding tools daily and read everything they generate before it merges. I keep a public build log of what I tried, what broke, and what I changed — [Lab Notebook](https://thalyanns.vercel.app/notebook). Failure modes are the most useful thing I own.
